LLM Usage Log

LLM Usage Log

The following section highlights how LLM tools, such as ChatGPT, were utilized to support various aspects of this project, including brainstorming, writing, code assistance, and debugging and literature search.

Brainstorming

To establish a clear direction for the project, LLM tools were used to brainstorm and refine the research questions for the dataset. ChatGPT provided guidance on developing meaningful research questions that align with the data structure and project goals. This step ensured that the analysis focused on relevant and impactful areas.

Writing

  • Unsupervised Learning Analysis: I requested ChatGPT’s assistance in analyzing the visualization results of K-Means clustering. Specifically, ChatGPT helped explain the occurrence of uniform clusters in the t-SNE visualization and provided insights into the reasons behind the observed patterns.
  • Supervised Learning Explanation: For the supervised learning portion, I asked ChatGPT to explain the unusually high accuracy (accuracy = 1) observed in the Random Forest and Gradient Boosting models. ChatGPT provided explanations for potential causes, including the likelihood of overfitting, and suggested methods such as introducing noise and cross-validation to verify the model’s robustness.
  • Mathematical Methods: ChatGPT was also consulted for detailed explanations and formulas of the supervised and unsupervised learning methods applied in the project.

Code

  • LaTeX Formulas: ChatGPT provided LaTeX code for key mathematical formulas used in the methodology section of the report, ensuring the equations were correctly formatted and clear.
  • Debugging Assistance: During implementation, I requested ChatGPT’s help to debug specific Python code errors, streamline sections of code, and improve its efficiency.

Literature Search

To strengthen the theoretical foundation of the project, I used ChatGPT to search for relevant academic papers on machine learning applications in healthcare. This process involved generating queries for topics such as “health risk prediction,” “chronic disease management,” and “machine learning in healthcare.” ChatGPT provided summaries, bibliographic details, and direct download links for selected research papers, streamlining the literature review process and enabling an in-depth exploration of related work.

Research Paper Search Process

To support the literature review and strengthen the theoretical foundation of this project, I conducted an extensive search for relevant research papers using the Google Scholar API through the scholarly library. This search focused on papers related to machine learning in healthcare, health risk prediction, and chronic diseases management.

The primary objective was to gather high-impact papers that cover diverse aspects of the field, including supervised and unsupervised learning applications, feature engineering techniques, and public health implications. By querying terms such as “machine learning in healthcare,” “health risk prediction,” and “chronic disease management,” I retrieved 50 relevant papers.

Key bibliographic details, including title, authors, publication venue, year of publication, abstract, and direct download links, were extracted and organized into a structured CSV file. This systematic approach allowed efficient reference management, enabling comprehensive literature analysis to inform both the methodology design and the interpretation of results.

The collected papers serve as a vital resource, providing insights into previous methodologies, existing challenges, and proposed solutions in the healthcare machine learning domain. This research-driven approach enhances the academic rigor of the project while ensuring its alignment with current advancements in the field.

Code 
from scholarly import scholarly
import pandas as pd

# Define search query
query = "machine learning in healthcare health risk prediction chronic diseases"

# Search for papers
search_results = scholarly.search_pubs(query)

# Collect top 50 papers
papers = []
for i in range(50):
    try:
        paper = next(search_results)
        papers.append({
            'Title': paper['bib']['title'],
            'Authors': ', '.join(paper['bib']['author']),
            'Publication': paper['bib'].get('venue', 'N/A'),
            'Year': paper['bib'].get('year', 'N/A'),
            'Abstract': paper['bib'].get('abstract', 'N/A'),
            'Link': paper['eprint_url'] if 'eprint_url' in paper else "N/A"
        })
    except StopIteration:
        break

# Save to CSV
papers_df = pd.DataFrame(papers)
papers_df.to_csv('../../data/paper/research_paper', index=False)

print("Saved top 50 papers to research_papers.csv")
